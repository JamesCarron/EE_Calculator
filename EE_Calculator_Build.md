# EE Calculator — build task summary

## Goal

Create a new tool at `C:\Auterion\Tools\EE_Calculator\`: a web interface for simple EE calculations, with a dedicated resistor divider tab (feature set modelled on https://sagecalculator.com/resistance-divider-calculator/), set up as a git repo with a pixi environment and committed incrementally.

## Current state

Done and verified. The tool is a single self-contained page, `EE_Calculator.html`, generated by `build_page.py` (`pixi run build`). Ten tabs. The circuit tabs: Ohm's Law & Power (enter any two of V/I/R/P), Resistor Divider (a single unified solver — the earlier separate finder card is folded in), Series/Parallel resistance, RC filter cutoff, Reactance (Xc, Xl, LC resonance), and LED series resistor (with next-standard-value-up suggestion). The E-series for all standard-value suggestions (divider solver, pair finder, LED) is one top-level select in the tab bar, default E96; changing it recalculates the three consumers. The divider solver takes any three of Vin, Vout, R1, R2 — plus an optional constant load current drawn out of the midpoint (KCL: I_R1 = I_R2 + I_load) and an optional total resistance — and solves whatever is missing as soon as it has enough: three of four → the fourth (all four → Vout check mode); one leg + total → the other leg stands in; Vin + Vout + total → both exact legs (unloaded R1 = (Vin−Vout)·T/Vin; loaded, the smaller root of IL·R1² − (Vin+IL·T)·R1 + (Vin−Vout)·T = 0); Vin + Vout alone → a load-aware search of E-series pairs ranked by loaded-Vout error, steered toward the total when given. A solved resistor gets the nearest E-series value and the real loaded Vout with it (Vout = (Vin − R1·I_L)/(1 + R1/R2)); every solve also reports ratio, currents, powers, total R, and a bleed/load stiffness ratio with a warning below 10. It originally shipped as three cards (plain calculator + design-one-leg + pair finder), merged 2026-08-26 at the user's request. Each tab carries an inline SVG schematic of its topology (divider schematic includes the dashed optional load branch), drawn with `currentColor`/house tokens so it tracks light/dark. All inputs accept SI suffixes including `4k7` style.

Four PCB-oriented tabs were added 2026-08-27 after comparing against the Saturn PCB Toolkit (see the feature-selection decision below). **PCB Power**: trace width ↔ current by IPC-2221 (I = k·ΔT^0.44·A^0.725, k = 0.048 external / 0.024 internal, area in mil²) solving either direction or reporting margin when both are given, plus temperature-corrected resistance, drop and power over an optional length; via ampacity/resistance/inductance/capacitance/thermal resistance from drill, plating, board thickness and optional pad+antipad; Onderdonk fusing current; and the full IPC-2221 Table 6-1 spacing matrix (B1–B4, A5–A7) including the >500 V per-volt extrapolation. **Impedance**: IPC-2141 first-order microstrip and stripline Z₀ with explicit validity-range warnings, ε_eff, propagation delay; wavelength/λ-fractions, knee frequency (0.35/t_r) and critical length (t_r·v_p/2). **Crystal**: Pierce C_L = C1·C2/(C1+C2) + C_stray solved either direction with a 3 pF default stray, and ppm ↔ Δf with clock drift per day/year. **Utilities**: AWG −3…40 (diameter from the 92^((36−n)/39) definition, area, resistance, both handbook ampacities) and live-linked mm/mil, °C/°F, dB/voltage-ratio/power-ratio conversions.

Dimension fields on the PCB and impedance tabs parse mm by default and accept `mil`, `um` and `in` suffixes, via a separate `parseDimMM`/`valDim` pair — deliberately distinct from the SI-suffix `parseVal` used everywhere else, because `10m` means ten metres in one context and ten milli-anything in the other. Git repo has 6 commits; pixi env is instantiated (python 3.12, `build` task). The calculation logic was smoke-tested by extracting the page JS and running it in node with a stubbed DOM — divider (12 V, 10k/4k7 → 3.837 V, 816.3 µA), Ohm's law both directions, RC (10k/100n → 159.2 Hz), reactance/LC resonance, LED (5 V, 2.1 V, 10 mA → 290 Ω exact, 300 Ω E24), and the finder (12→3.3 V E24 → 0.027 % error pairs) all match hand calculations.

## Key decisions

- **Logic lives in JS, not Python.** The house rule prefers Python logic, but this page is inherently runtime-interactive with no server, so JS is the engine and Python (`build_page.py`) is only the build harness that assembles the page and inlines the house stylesheet via `Tools\brand\auterion_inline`. There is no duplicate Python implementation, so no parity test is owed.
- **No server, no launch URL.** The page opens straight from the filesystem; `EE_Calculator.bat` rebuilds (when pixi exists) and opens it. This makes the tool a natural candidate for GitHub Pages hosting later, per `Tools\altium_apps\External_Hosting_Plan.md` conventions.
- **The generated HTML is committed** so the tool works for users without pixi; the .bat regenerates it when pixi is present.
- **Resistor finder algorithm:** for each E-series R1 across decades 10 Ω–9.76 MΩ, snap the ideal R2 = R1·Vout/(Vin−Vout) to the same series, rank by relative Vout error with a log-distance penalty toward the requested total resistance; show top 5 deduplicated pairs with Vout, error %, current, and total R.
- **Deep links:** `EE_Calculator.html#div` opens the divider tab directly.
- **Schematics are hand-drawn inline SVG, not Altium/LTspice exports.** The user asked whether Altium or LTspice could generate the topology visuals: neither has a workable headless schematic-to-image path (LTspice renders schematics only in its GUI with no export CLI; Altium would need the full application plus scripting per build and its output is not theme-aware or self-containable). Inline SVG using `currentColor` and house tokens is crisp at any zoom, follows the page theme, and keeps the file self-contained. If real Altium-drawn captures are ever wanted, they would be manual image exports embedded as data URIs — a downgrade for this use.
- `user_data/` exists and is gitignored per the Altium-tools distribution convention, though this tool currently stores nothing.
- **Saturn PCB Toolkit comparison (2026-08-27).** The user asked for feature suggestions based on the Saturn PCB Design Toolkit. Assessed its whole tab list and proposed the subset that is both genuinely useful for drone power electronics and implementable from freely published equations; the user selected all four proposed groups (PCB power, crystal+ppm, utilities, impedance+wavelength). Deliberately **not** implemented: planar inductors, embedded resistors, BGA/padstack land patterns (Altium already does these), PDN target impedance, and crosstalk — niche or better served by existing tools. Differential-pair impedance was also left out: the empirical formulas are markedly less accurate than the single-ended ones and would invite misplaced trust.
- **IPC-2221, not IPC-2152, for current capacity.** IPC-2152's data is chart-based and lives in a paywalled standard; IPC-2221's closed-form equation is freely published. The trace card names the method on the page and notes that 2152 permits somewhat more current, so the tool is conservative rather than silently wrong — the failure mode of web calculators that claim 2152 while implementing 2221.
- **Impedance formulas carry validity warnings rather than false precision.** The IPC-2141 microstrip/stripline equations are good to a few percent only inside their geometry range, so the tab warns when w/h or t/b leaves it and the tab hint says to confirm against the fab's field solver.

## How to continue

Edit the template in `build_page.py`, run `pixi run build` (or `EE_Calculator.bat`), and refresh the browser tab — a page edit only needs a rebuild + refresh, there is no server to restart. Add a new tab by adding a `<button data-tab=...>` to the tab bar, a `<section class="panel" id="panel-...">`, a calc function, and an entry in the `CALCS` map. Commit per feature.
