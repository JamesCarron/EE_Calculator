# EE Calculator — build task summary

## Goal

Create a new tool at `C:\Auterion\Tools\EE_Calculator\`: a web interface for simple EE calculations, with a dedicated resistor divider tab (feature set modelled on https://sagecalculator.com/resistance-divider-calculator/), set up as a git repo with a pixi environment and committed incrementally.

## Current state

Done and verified. The tool is a single self-contained page, `EE_Calculator.html`, generated by `build_page.py` (`pixi run build`). Six tabs: Ohm's Law & Power (enter any two of V/I/R/P), Resistor Divider (a single unified solver — the earlier separate finder card is folded in), Series/Parallel resistance, RC filter cutoff, Reactance (Xc, Xl, LC resonance), and LED series resistor (with next-standard-value-up suggestion). The E-series for all standard-value suggestions (divider solver, pair finder, LED) is one top-level select in the tab bar, default E96; changing it recalculates the three consumers. The divider solver takes any three of Vin, Vout, R1, R2 — plus an optional constant load current drawn out of the midpoint (KCL: I_R1 = I_R2 + I_load) and an optional total resistance — and solves whatever is missing as soon as it has enough: three of four → the fourth (all four → Vout check mode); one leg + total → the other leg stands in; Vin + Vout + total → both exact legs (unloaded R1 = (Vin−Vout)·T/Vin; loaded, the smaller root of IL·R1² − (Vin+IL·T)·R1 + (Vin−Vout)·T = 0); Vin + Vout alone → a load-aware search of E-series pairs ranked by loaded-Vout error, steered toward the total when given. A solved resistor gets the nearest E-series value and the real loaded Vout with it (Vout = (Vin − R1·I_L)/(1 + R1/R2)); every solve also reports ratio, currents, powers, total R, and a bleed/load stiffness ratio with a warning below 10. It originally shipped as three cards (plain calculator + design-one-leg + pair finder), merged 2026-08-26 at the user's request. Each tab carries an inline SVG schematic of its topology (divider schematic includes the dashed optional load branch), drawn with `currentColor`/house tokens so it tracks light/dark. All inputs accept SI suffixes including `4k7` style. Git repo has 4 commits; pixi env is instantiated (python 3.12, `build` task). The calculation logic was smoke-tested by extracting the page JS and running it in node with a stubbed DOM — divider (12 V, 10k/4k7 → 3.837 V, 816.3 µA), Ohm's law both directions, RC (10k/100n → 159.2 Hz), reactance/LC resonance, LED (5 V, 2.1 V, 10 mA → 290 Ω exact, 300 Ω E24), and the finder (12→3.3 V E24 → 0.027 % error pairs) all match hand calculations.

## Key decisions

- **Logic lives in JS, not Python.** The house rule prefers Python logic, but this page is inherently runtime-interactive with no server, so JS is the engine and Python (`build_page.py`) is only the build harness that assembles the page and inlines the house stylesheet via `Tools\brand\auterion_inline`. There is no duplicate Python implementation, so no parity test is owed.
- **No server, no launch URL.** The page opens straight from the filesystem; `EE_Calculator.bat` rebuilds (when pixi exists) and opens it. This makes the tool a natural candidate for GitHub Pages hosting later, per `Tools\altium_apps\External_Hosting_Plan.md` conventions.
- **The generated HTML is committed** so the tool works for users without pixi; the .bat regenerates it when pixi is present.
- **Resistor finder algorithm:** for each E-series R1 across decades 10 Ω–9.76 MΩ, snap the ideal R2 = R1·Vout/(Vin−Vout) to the same series, rank by relative Vout error with a log-distance penalty toward the requested total resistance; show top 5 deduplicated pairs with Vout, error %, current, and total R.
- **Deep links:** `EE_Calculator.html#div` opens the divider tab directly.
- **Schematics are hand-drawn inline SVG, not Altium/LTspice exports.** The user asked whether Altium or LTspice could generate the topology visuals: neither has a workable headless schematic-to-image path (LTspice renders schematics only in its GUI with no export CLI; Altium would need the full application plus scripting per build and its output is not theme-aware or self-containable). Inline SVG using `currentColor` and house tokens is crisp at any zoom, follows the page theme, and keeps the file self-contained. If real Altium-drawn captures are ever wanted, they would be manual image exports embedded as data URIs — a downgrade for this use.
- `user_data/` exists and is gitignored per the Altium-tools distribution convention, though this tool currently stores nothing.

## How to continue

Edit the template in `build_page.py`, run `pixi run build` (or `EE_Calculator.bat`), and refresh the browser tab — a page edit only needs a rebuild + refresh, there is no server to restart. Add a new tab by adding a `<button data-tab=...>` to the tab bar, a `<section class="panel" id="panel-...">`, a calc function, and an entry in the `CALCS` map. Commit per feature.
